Threads連携ツール プライバシーポリシー

最終更新: 2026年7月30日 ／ 対象アプリ: Nightlife Industry Research Monitor

本ページは、GRACE SELECTION（運営: 出雲匠）が業務上のリサーチ目的で運用する Threads API 連携ツール「Nightlife Industry Research Monitor」における、 データの取得と取り扱いについて定めるものです。 サイト全体のプライバシーポリシーは こちら をご覧ください。

1. このツールの位置づけ

  • 運営者本人のみが使用する内部ツールです。第三者への提供・一般公開・販売は行いません。
  • 一般利用者向けのサービスではなく、アカウント登録機能もありません。
  • 利用目的は、grace-sc.com に掲載する記事・動画コンテンツの企画にあたって、 業界に関する公開の議論の傾向を把握することに限られます。

2. 取得する情報

  • 運営者自身のプロフィール情報（ユーザーID・ユーザー名） — Threads へのログイン時に threads_basic により取得します。
  • 公開投稿の情報（投稿ID・本文・パーマリンク・投稿日時） — threads_keyword_search により、公開されている投稿のみを対象に取得します。

非公開アカウントの投稿、ダイレクトメッセージ、メールアドレス、電話番号、 その他の連絡先情報は一切取得しません。

3. 利用目的

取得した情報は、業界内で現在どのような話題・疑問が語られているかを運営者が把握し、 コンテンツの企画判断に用いるためだけに使用します。 広告配信、プロフィリング、機械学習モデルの学習には使用しません。

4. 保存と削除

  • 取得した投稿データをデータベースに永続保存することはありません。
  • 検索結果は運営者個人の非公開 Slack チャンネルに通知され、運営者が手動で確認します。 通知に含まれるのはパーマリンクと投稿日時のみです。
  • アクセストークンは実行環境のローカルにのみ保持し、有効期限切れとともに失効します。 連携を解除したい場合は Threads のアプリ連携設定から取り消すことができ、 取り消し後はトークンが直ちに無効になります。
  • データの削除をご希望の場合は、下記の連絡先までご連絡ください。

5. 第三者提供

取得した情報を第三者に提供・共有・売却することはありません。 取得した投稿を再掲載・転載することもありません。

English summary

Nightlife Industry Research Monitor is an internal, single-user research tool operated by Takumi Izumo, who runs grace-sc.com, a Japanese-language media site covering the nightlife and hospitality industry. It is not distributed to any third party and has no consumer users.

Data accessed

  • threads_basic — the operator's own user ID and username, used only to identify the authenticated account.
  • threads_keyword_search — public posts only: post ID, text, permalink and timestamp.

How it is used — solely as editorial research input, to understand which topics and questions are currently being discussed in the industry, so that articles and short videos can be planned around them.

Retention — no platform data is stored in any database. Search results are forwarded to the operator's private Slack channel (permalink and timestamp only) and reviewed manually. Access tokens are held locally and expire; the user can revoke the connection at any time from the Threads app settings, which invalidates the token immediately.

Never — the data is never shared with third parties, never sold, never republished, never used for advertising or profiling, and never used to train machine learning models. Private accounts, direct messages and contact information are never accessed.

Contact / deletion requests — takumi.poker1@gmail.com
